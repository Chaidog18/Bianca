# Will You Be My Girlfriend? 💗

A minimalist, adorable, and interactive romantic website to ask someone special: **“Will you be my girlfriend?”**

Built with **React**, **Vite**, **Tailwind CSS**, and **Express / Vercel Serverless**, complete with custom GIF uploads, floating decorations, audio player, viral shrinking NO prank mode, and persistent shareable links.

---

## 🚀 Deploying to Vercel (Fast & Easy)

### Option 1: Via GitHub (Recommended)

1. **Create a new repository on GitHub:**
   - Go to [github.com/new](https://github.com/new)
   - Name your repository (e.g. `will-you-be-my-girlfriend`)
   - Leave it empty (do NOT check "Initialize with README")

2. **Push your code to GitHub:**
   Run these commands in your project terminal:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   git push -u origin main
   ```

3. **Deploy with Vercel:**
   - Go to [vercel.com](https://vercel.com) and log in.
   - Click **"Add New..."** > **"Project"**.
   - Select your GitHub repository.
   - Framework Preset: **Vite** (auto-detected).
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Click **Deploy**! 🎉

Your website will be live on `https://your-project.vercel.app` in under a minute!

## ✨ Features

- **Tender Romantic Journey:**
  - Opening Greeting with cute animations
  - Personal heartfelt message
  - The Main Question with YES & playful NO interactions
  - Celebratory confetti & heart explosion on YES
  - Unfolding digital love letter with progressive typing reveal
- **Viral Prank Mode:**
  - NO button moves and shrinks smaller and smaller (down to 25%!)
  - YES button expands larger to fill the screen
  - Infinite playful loop of excuses
- **Honest Rejection Mode:**
  - Dedicated, dignified Rejection Screen with no infinite loop
- **GIF Upload & Floating Animations:**
  - Upload custom `.gif`, `.png`, `.jpg`, `.webp` files
  - 6 display modes: Floating, Random appearance, Corner decoration, Scattered, Click-to-show heart, and Custom placement
- **Background Romantic Melody:**
  - Soft built-in Web Audio chime / music-box melody (zero external dependencies)
  - Custom audio URL support with volume controls
- **Full Customization Editor:**
  - Real-time text preview, draft saving, and unique shareable link generator
